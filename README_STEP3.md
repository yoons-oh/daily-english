# 3단계 적용 방법

## 포함 내용

- 오늘의 대화 자동 추천 시스템
- 이미 학습한 대화는 우선 제외
- 모두 학습하면 전체 콘텐츠에서 다시 순환 추천
- 저작권 위험 없는 오리지널 실생활 회화 30개 추가
- 홈 화면 전체 콘텐츠 수 표시

## 적용 방법

1. 이 ZIP 파일을 압축 해제합니다.
2. 기존 프로젝트에 파일을 덮어씁니다.

대상 폴더:

```text
C:\AI kg\daily-english
```

3. Supabase SQL Editor에서 아래 파일 내용을 전체 실행합니다.

```text
supabase/step3_recommendation_and_30_contents.sql
```

4. 개발 서버 재시작

```bash
Ctrl + C
npm run dev
```

## 확인할 것

- 홈 화면에서 전체 콘텐츠 30개 이상 표시
- 오늘의 대화가 DB에서 추천됨
- 학습 완료 후 다음 추천 후보에서 제외됨
- 복습 추가 가능
- 기록 페이지에 학습 기록 표시
