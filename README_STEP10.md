# STEP10 TTS 영어 읽기 기능

## 추가 기능

- 영어 전체 대화 듣기
- 문장별 🔊 버튼으로 개별 문장 듣기
- 읽기 속도 조절
- 영어 음성 선택
- 오늘의 대화와 전체 대화 상세 화면 모두 적용
- 별도 API 비용 없음, 브라우저 기본 Web Speech API 사용

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```

## 참고

브라우저/운영체제에 따라 제공되는 영어 음성이 다를 수 있습니다.
Chrome 또는 Edge 권장입니다.
