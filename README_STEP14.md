# STEP14 학습 완료 중복 저장 오류 수정

## 수정 내용

이미 완료한 학습에서 다시 완료 버튼을 누르면 중복 저장 오류가 나던 문제를 수정했습니다.

## 변경 사항

- 완료 저장 전 기존 학습 기록 확인
- 이미 저장된 학습이면 DB 저장하지 않음
- 메시지: “이미 저장한 학습입니다. 홈으로 돌아가겠습니까?”
- 확인 누르면 홈으로 이동
- 취소 누르면 현재 화면 유지
- 오늘의 대화, 대화목록 상세 화면 모두 동일 적용
- 쉐도잉 화면에서 완료 버튼을 눌러도 동일하게 처리

