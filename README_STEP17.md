# STEP17 화면 이동 스크롤 맨 위 + 반복듣기 화면 꺼짐 방지

## 추가 기능

### 화면 이동
- 메뉴 클릭 후 라우트 변경 시 스크롤 맨 위로 이동
- 메인 영역 포커스 이동

### 반복 듣기 개선
- 반복 듣기 정지 안정화
- 반복 듣기 중 화면 꺼짐 방지 옵션 추가
- Media Session 기본 메타데이터 추가
- 반복 1~10회 유지

## 중요한 제한

현재 TTS는 브라우저 기본 Web Speech API를 사용합니다.

iPhone/Android 모바일 브라우저는 사용자가 전원 버튼으로 화면을 직접 끄면
JavaScript와 Web Speech API가 중단될 수 있습니다.

그래서 이번 구현은 다음 방식입니다.

- 반복 듣기 중 화면이 자동으로 꺼지지 않도록 Wake Lock 사용
- 브라우저가 지원하지 않으면 안내 메시지 표시
- 화면을 직접 끈 상태의 완전한 백그라운드 재생은 네이티브 앱 또는 실제 오디오 파일 기반 재생이 필요함
