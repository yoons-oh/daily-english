# 4단계 대화 화면 레이아웃 수정

## 수정 내용

기존에는 문장마다 카드가 따로 나뉘어 있어 대화 흐름이 끊겼습니다.

이번 수정에서는 다음처럼 변경했습니다.

- 한 박스 안에 대화가 이어서 표시됨
- A/B 화자가 좌우 말풍선으로 구분됨
- 영어 탭 / 한글 탭은 그대로 유지
- 모바일에서도 한눈에 읽기 좋게 개선
- 학습 완료, 복습 추가, 영어 다시 보기 기능 유지

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```
