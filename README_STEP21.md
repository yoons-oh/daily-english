# STEP21 복습/홈/연속학습 개선

## 반영 내용

### 홈 화면
- 완료한 학습 / 복습대기 / 전체 콘텐츠 카드 제거
- 오늘 학습 중심 화면으로 단순화
- 연속학습 streak 표시
- 오늘 학습 완료 여부 표시
- 최근 학습 3개 표시

### 복습 화면
- 복습 목록 클릭 시 학습 화면으로 이동
- “다시 학습하기” 버튼 추가
- 기록 화면과 역할 분리

### 기록 화면
- 연속학습
- 총 학습 수
- 완료 대화 수
- 완료한 학습 목록
- 완료 기록 클릭 시 학습 화면 이동
