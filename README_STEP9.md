# STEP9 오늘의 학습 고정 기능

## 변경 이유

오늘의 학습은 하루 학습용이므로, 접속할 때마다 다른 대화가 나오면 안 됩니다.

## 추가 기능

- 오늘 처음 접속하면 오늘의 대화 1개를 배정
- 같은 날 다시 접속해도 같은 대화 표시
- 학습 완료 후에도 그날은 같은 대화 유지
- 다음날이 되면 새로운 대화 배정
- 추가로 공부하고 싶은 대화는 “대화목록”에서만 직접 선택

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. Supabase SQL Editor에서 실행

```text
supabase/step9_daily_assignments.sql
```

4. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```

## 확인할 것

- 오늘 메뉴에 들어가면 하나의 대화가 배정됨
- 새로고침해도 같은 대화 유지
- 로그아웃 후 다시 로그인해도 같은 대화 유지
- 대화목록에서 추가 학습 가능
