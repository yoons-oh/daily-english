# STEP8 카테고리/전체 대화 탐색 화면

## 추가 내용

- 대화목록 메뉴 추가
- 전체 대화 목록 화면 추가
- 카테고리 필터
- 검색 기능
- 학습 완료 여부 표시
- 원하는 대화를 직접 열어서 학습 가능
- 오늘의 대화와 동일한 영어/한글/녹음/완료/복습 UI 적용

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```

## 확인할 것

- 상단 메뉴에 “대화목록” 표시
- 카테고리별 필터 가능
- 검색 가능
- 대화 클릭 시 학습 화면 이동
- 학습 완료/복습 저장 가능
