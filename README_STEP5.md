# 5단계 대화 UI 재수정

## 수정 내용

이전 말풍선 UI는 B 화자의 라벨이 문장 뒤에 나와서 어색했습니다.

이번 수정에서는 다음처럼 변경했습니다.

- A/B 라벨이 모든 줄에서 왼쪽에 고정
- 문장이 오른쪽에 정렬되어 자연스럽게 읽힘
- 한 박스 안에서 대화가 이어짐
- 카드가 너무 많이 나뉘지 않음
- 성인용 학습 앱에 맞게 더 깔끔한 스크립트형 UI 적용
