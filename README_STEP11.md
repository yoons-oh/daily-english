# STEP11 Shadowing 모드

## 추가 기능

쉐도잉 모드를 추가했습니다.

학습 흐름:

1. 영어 문장 듣기
2. 자동 일시정지
3. 사용자가 따라 읽기
4. 녹음
5. 내 녹음 다시 듣기
6. 다음 문장 진행

## 적용 화면

- 오늘의 대화
- 전체 대화 상세 화면

## 하단 버튼

기존 하단 버튼에 “쉐도잉” 버튼이 추가됩니다.

```text
완료 / 복습 / 듣기 / 녹음 / 쉐도잉
```

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```

## 참고

마이크 권한이 필요합니다.
녹음 파일은 서버에 저장하지 않고 브라우저에서만 재생합니다.
