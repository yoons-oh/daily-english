# STEP13 쉐도잉 엔진 안정화

## 수정 내용

쉐도잉 중 두 번째 문장부터 여러 번 읽히는 문제를 수정했습니다.

## 반영 사항

- 중복 실행 금지
- TTS 1회만 재생
- 중앙 타이머 1개만 사용
- 듣기 → 0.3초 대기 → 5초 자동 녹음 → 0.3초 대기 → 다음 문장
- 기본 녹음 시간 5초 고정
- 현재 문장 하이라이트
- 현재 문장 pulse 애니메이션
- 현재 문장 자동 스크롤
- 완료 시 전체 완료 애니메이션
- 완료한 문장은 체크 표시

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```
