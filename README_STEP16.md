# STEP16 붙여넣기 대화 추가 + 반복 듣기

## 추가 기능

### 대화 추가
- 영어 대화 전체 붙여넣기
- 한글 번역 전체 붙여넣기
- 줄 단위 자동 분리
- A:/B: 자동 인식
- 미리보기 후 수정 가능
- 최소 8줄 검사

### 듣기
- 전체 문장 반복 듣기
- 반복 횟수 1~10회 설정
- 읽기 속도 조절 유지
- 음성 선택 유지
