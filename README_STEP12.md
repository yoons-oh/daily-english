# STEP12 자동 쉐도잉 모드 개선

## 개선 이유

이전 방식은 문장을 하나씩 넘기고 녹음 버튼을 직접 눌러야 해서 귀찮았습니다.

## 변경 내용

- 전체 대화를 한 화면에 그대로 표시
- 현재 문장만 하이라이트
- 시작 버튼 한 번으로 흐름 진행
- 영어 문장 듣기
- 자동 일시정지
- 자동 녹음 시작
- 지정 시간 후 자동 녹음 종료
- 다음 문장 자동 진행
- 각 문장 아래에 내 녹음 표시
- 자동 다음 ON/OFF
- 녹음 시간 3~7초 조절

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```
