# STEP15 사용자 대화 추가 기능

## 추가 기능

- 상단 메뉴 “대화추가”
- 사용자가 직접 대화 추가
- 제목 / 상황 / 카테고리 입력
- A/B 대화 8줄 이상 입력
- 영어 문장 + 한글 번역 저장
- 저장 후 바로 학습 화면 이동 가능
- 대화목록에서 “내 대화” 필터 추가
- 내가 만든 대화도 TTS / 녹음 / 쉐도잉 / 완료 / 복습 가능

## 적용 방법

1. ZIP 압축 해제
2. 아래 폴더에 덮어쓰기

```text
C:\AI kg\daily-english
```

3. Supabase SQL Editor에서 실행

```text
supabase/step15_user_conversations.sql
```

4. 개발 서버 재실행

```bash
Ctrl + C
npm run dev
```
